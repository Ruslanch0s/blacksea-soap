# Союз сетевых решений

Публичная страница службы технической поддержки. Заявки принимает официальный бот [@ssr_client_bot](https://t.me/ssr_client_bot): текст обращения, номер заявки и ответ специалиста в том же чате.

Страница публикуется GitHub Pages из корня ветки `main`. В ней нет приглашений, личных подписок и конфигураций. Основной `index.html` самодостаточный, без внешних скриптов и сетевых зависимостей при открытии.
