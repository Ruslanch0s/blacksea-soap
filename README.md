# Черноморская мыловаренная компания

Публичная информационная страница марки. Статические HTML и CSS, без аналитики, внешних шрифтов и форм сбора данных.

В репозитории нет персональных конфигураций, ключей, адресов инфраструктуры или иных закрытых данных. Закрытый раздел работает отдельно от GitHub Pages.

Публикация: GitHub Pages, ветка `main`, корень репозитория.
